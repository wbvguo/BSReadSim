# Introduction
BSReadSim (<u>B</u>isulfite <u>S</u>equencing <u>Read</u> <u>Sim</u>ulator) is derived from [BSBolt](https://github.com/NuttyLogic/BSBolt) simulation module, but sysmtematically optimized to allow for profile-based simulation. To our best knowledge, BSReadSim is the only bisulfite sequencing read simulator that allows user to incooperate the reference SNPs and methylation profile with high fidelity, thus it can generate more realistic bisulfite sequencing reads compared to other widely-used tools. For more details, please refer to the following table:

Features | Sherman | BSBolt | BSReadSim
----| ---- | ---- | ---- |
bisulfite conversion input | yes | no | yes
methylation profile input | no | $\text{yes}^*$ | yes
genetic variant input | no   | no | yes
site-site dependency | no | no | yes

($\text{yes}^*$: BSBolt allows users to input the methylation profile, but used the profile as a reference pool. During methylation status simulation, it randomly picks a methylation value from this pool. As a result, the simulated data and the reference profile will not have the same methylation level at same CG site)

# Installation
## install from github
```
git clone https://github.com/wbvguo/BSReadSim.git
cd BSReadSim
pip install -e .
```


# Usage
## Command
```
BSReadSim ...
```

## Input format
1. reference genome: [fasta](https://en.wikipedia.org/wiki/FASTA_format) format (accept `.fa` or `.fa.gz`)
2. methylation profile: [`CGmap`](https://bsbolt.readthedocs.io/en/latest/methylation_calling/) format generated by BSBolt (accept `.CGmap` or `.CGmap.gz`)
3. SNP: [VCF](https://samtools.github.io/hts-specs/VCFv4.2.pdf) format, v4.2 or later (accept `.vcf` or `.vcf.gz`)
